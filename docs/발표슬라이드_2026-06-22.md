## 4 — 기획 의도
- 리듬게임은 보통 "제자리"에서 점수만 → **이동(레이스)+경쟁**을 더해 긴장감
- VR은 몸을 쓰는 매체 → 버튼이 아닌 **실제 팔 동작**의 손맛

📷 플레이어가 팔을 휘두르는 모습(헤드셋 착용 사진) 또는 동작 컨셉 이미지
🎤 "리듬게임은 보통 가만히 서서 점수만 쌓죠. 여기에 레이싱의 경쟁을 붙이면 '잘 치면 앞서간다'는 직접적인 동기가 생깁니다. VR이니 실제로 팔을 휘둘러 칩니다."

---

## 5 — 차별점 3가지
1. **실력 = 속도** — 잘 칠수록 보트가 빨라짐 (AI는 따라하지 않음)
2. **교실에서 4인 멀티** — LAN 기반, 인터넷 없이 한 공간 대전
3. **역전 아이템** — 꼴찌일수록 강한 견제템 → 끝까지 모름

🎤 "차별점 셋입니다. 특히 LAN이라 인터넷 없이 교실에서 바로 4명이 붙는 게 강점입니다."

# ░ 섹션 2. 핵심 게임플레이 ░

## 6 — 코어 루프 (다이어그램)
```
노트 등장 → 색 맞는 손/도구로 타격 → 콤보·속도 ↑ → 보트 전진 → 순위
                         ↘ 아이템 노트 → 자기강화 / 상대 견제 ↗
```

🎨 위 흐름을 **아이콘 다이어그램**으로 시각화(노트→손→속도게이지→결승)
🎤 "게임의 핵심 사이클입니다. 노트를 치면 콤보·속도가 오르고 보트가 빨라집니다. 아이템 노트로 나를 강화하거나 상대를 방해합니다."

---

## 7 — 노트 & 타격
- 노트 4종을 **색**으로 구분
- 동작: 빈손 터치 / 잡기 / 트리거 / 양손(아이템)
- 노트는 팔 거리 앞에서 처리 + 맞으면 튕겨나감(시야 안 가림)

📷 노트가 손에 맞아 튕기는 순간 스크린샷
🎤 "노트는 색으로 구분되고 색마다 처리하는 손/동작이 다릅니다. 노트가 얼굴까지 오지 않고 팔 거리에서 처리되며, 맞으면 튕겨 나가 시야를 안 가립니다 — VR 가독성 때문입니다."

---

## 8 — 🎨 노트 디자인 (에셋 소개)
- 파랑/초록/빨강 **날치(nana)** = 일반 노트 (색 = 손 매칭)
- 흰 **새(Bird)** = 아이템 노트
- 스폰 시 자동 Unlit 전환(선명·시인성)

🎨 **노트 모델 3색 날치 + 흰 새** 렌더 이미지 나란히
🎤 "노트는 캐릭터성을 살려 색깔 날치로 디자인했습니다. 색이 곧 어떤 손으로 칠지를 알려주고, 흰 새는 아이템 노트입니다."

---

## 9 — 실력이 곧 속도
- **콤보**: 미스 시 0 리셋 (리듬 정석)
- **속도**: 히트 +가속 / 미스 −감속 **누적** (한 번 실수해도 0은 아님)
- 속도: 시작 ~6 → 잘하면 ~18-20 m/s
- 타이밍 등급(Perfect) **없음** — VR 입력 특성상 부적합

🎨 속도 게이지/콤보 카운터 HUD 확대 이미지
🎤 "콤보는 미스하면 0이지만 보트 속도는 누적이라 완전히 멈추진 않습니다. 좌절을 줄이려는 설계입니다. VR 특성상 밀리초 판정은 안 맞아 등급 대신 '쳤다/놓쳤다'의 명확함에 집중했습니다."

## 12 — 아이템 5종

🎨 **아이템 5종 아이콘** 나란히 (자기강화 3 / 견제 2 구분)

## 13 — 아이템 역전 설계
- 아이템 노트 명중 시 **내 등수 가중**으로 추첨 (카트라이더식)
- 1등: 약한 자기강화 / 꼴찌권: 폭탄·우주선 확률↑
- 우주선은 내가 1등이면 안 나옴(무의미)

🎨 등수별 확률 분포 막대그래프(선두 vs 꼴찌)
🎤 "핵심은 등수 가중입니다. 1등은 약한 아이템, 꼴찌는 역전템이 잘 나와서 끝까지 순위를 모르게 했습니다."

---

## 14 — 📷 멀티플레이 4인
- 호스트/조인 → 로비 레디 → 동시 출발
- **빈자리는 AI가 자동으로 채움** (2인이면 AI 2척)
- 결과: 완주 순위 + 완주 시간

📷 **멀티 로비 화면**(4인 카드/레디 상태) 스크린샷
🎤 "최대 4명, 빈자리는 AI가 채웁니다. 2명이 해도 AI 2척이 붙어 4척 레이스가 됩니다."

# ░ 섹션 5. 기술 설계 ░

## 19 — 기술 ① 가벼운 멀티 아키텍처
- 리듬·판정·속도 = **전부 로컬**
- 네트워크 동기화 = **보트 거리 + 아바타(머리·양손)만**
- 공격 아이템도 **RPC 신호만**, 효과는 대상 로컬
- → 가볍고 **지연에 강함** + 싱글 코드 재사용

🎨 **네트워크 동기화 다이어그램**(로컬 계산 박스 vs 네트워크로 가는 화살표 = 거리/아바타만)
🎤 "기술적으로 가장 신경 쓴 부분입니다. 무거운 리듬 계산은 각자 기기에서 하고, 네트워크로는 보트 위치와 아바타만 주고받습니다. 공격 아이템도 신호만 보내고 효과는 받는 기기에서 처리해 매우 가볍고 랙에 강합니다."

---

## 20 — 기술 ② VR 멀미 방지
- 직선 전진 + 모든 locomotion 잠금
- 앉은 시야(Tracking Origin=Device, Y 1.6)
- 출렁임은 배 모델에만, 카메라엔 회전 X
- 타격 판정 = 레퍼런스 프레임 로컬 속도 (배 움직여도 정확)

🎨 멀미 방지 체크리스트 아이콘
🎤 "VR은 멀미가 치명적이라, 회전은 카메라에 절대 주지 않고, 이동도 잠가서 배가 알아서 전진합니다."

---

## 21 — 기술 ③ BPM 자동 채보 파이프라인
- 음원(WAV) PCM 직접 분석
- **온셋 에너지 + 자기상관** → BPM·다운비트 자동 검출
- 비트 그리드 위에 난이도별 밀도로 채보 생성
- 정렬 객관 검증: 노트 위치 강도 = 평균의 **5~8배**

🎨 **온셋 파형 + 채보 정렬 그래프**(비트선에 노트가 얹힌 그림)
🎤 "채보를 손으로 다 찍는 대신, 음원을 분석해 BPM과 박자를 자동으로 찾아 채보를 생성하는 도구를 만들었습니다. 생성된 채보가 실제 음악과 맞는지 수치로도 검증했습니다."

---

## 22 — 기술 ④ 확장 가능한 구조
- 타격 도구 추상화: `hitPoint`만 교체(손·후라이팬·노) — 코드 0
- 노트/판정은 프로토 → **정식 리듬 엔진 교체 가능**
- 시스템 경계: 이벤트 계약으로 팀별 독립 개발

🎨 도구 교체(손→후라이팬→노) 컨셉 이미지
🎤 "타격 도구는 한 점만 바꾸면 무엇이든 됩니다. 노트와 판정도 정식 엔진으로 갈아끼울 수 있게 분리해 뒀습니다."

# ░ 섹션 6. 시연 & 마무리 ░

## 23 — 🎬 시연 영상
(영상 재생)

🎬 **영상 샷 순서**:
1. 타이틀 → 2. 곡 선택 → 3. 멀티 로비(4인 레디) → 4. 카운트다운→출발
→ 5. **1인칭: 노트 타격·콤보·속도↑ (가장 길게)** → 6. 견제 아이템
→ 7. 3인칭: 순위 경쟁 → 8. 결승 → 결과창(순위+시간)

🎤 "이제 실제 플레이를 보여드리겠습니다." (영상 중 핵심만 짚기)

---

## 24 — 시연 포인트 (영상 보며 강조)
- 노트 색 = 손 매칭, 맞으면 튕김
- **콤보↑ = 속도↑** (게이지 차오름)
- 아이템으로 순위 뒤집기
- 4척 동시 경쟁 + 완주 시간

🎤 "보시는 것처럼 잘 칠수록 속도 게이지가 차오르고, 막판에 아이템으로 순위가 뒤집힙니다."

---

## 25 — 개발 성과 요약
- 코어(리듬→속도→레이스) + **4인 실시간 멀티** 완성
- 곡 난이도 단계 + BPM 자동 채보
- 아이템 5종 + 역전 분배
- VR 멀미 방지 + 디자인 HUD/결과창

🎤 "정리하면, 코어 루프부터 4인 멀티, 곡·아이템·결과창까지 동작하는 데모를 완성했습니다."

---

## 26 — 향후 계획
- 정식 리듬 엔진/판정으로 교체
- 곡·코스·장애물 추가 + 난이도 밸런스
- 라이벌 서지(막판 역전 연출)
- 정식 타이틀·아트 폴리시

🎤 "정식으로 가면 리듬 엔진을 정식화하고 곡·코스·장애물을 늘릴 계획입니다."
