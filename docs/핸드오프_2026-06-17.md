### 2. 곡 선택 → 레이스 노트 통합 (CSV 채보)
- `ProtoBeatmapSpawner`: BPM 임시판 → **CSV 채보**(시간,레인 / songs[] clip+CSV / pre-roll dspTime 싱크). `SongSelection`(정적) 으로 타이틀→레이스 곡 전달.
- `ProtoNoteSpawner`: `SpawnNote(rng, lane)` — 레인=X위치, 종류/색=시드랜덤. **노트 렌더큐 3100**(물 3000 위 — 날치 가림 수정).
- 곡선택은 **컨트롤러 `SelectedPlaylistSongIndex` 를 브릿지가 직접 읽음**(빌더 버튼 재생성 무관). `TitlePlaylistSongListBuilder` **단일소스(songs[])+0-based** 정상화.
- 멀티: `NetRaceCoordinator.StartRaceClientRpc(seed, songIndex)` — 호스트 곡 전원 동기.

### 3. 타이틀 멀티 연결 + 리스타트→로비
- `TitleLobbyNetBridge`: 팀원 타이틀 버튼에 네트워크 동작 + 곡 전달. 세션 유지 복귀 시 **로비 화면**(터치투스타트 X).

- `NetRacer`: **레이스 중(RaceStarted)에만 hull 표시** — 로비/타이틀 배 숨김.
- `MultiplayerHud`: 호스트코드/버튼 패널 제거 → **카운트다운 숫자만**(font 통일 가능).
