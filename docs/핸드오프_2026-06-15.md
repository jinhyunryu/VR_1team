## 이번 기간 완성된 것

### 1. 4인 실시간 멀티플레이 (NGO + LAN, 동작 검증 완료)
- 스택: **NGO + Unity Multiplayer Services(Relay) + LAN 폴백**. 동기화 = 보트 거리(NetworkVariable) + 아바타(머리+양손). 리듬/판정/속도는 전부 로컬.
- 신규 `Assets/_Game/Scripts/Net/`: `SessionConnector`(UGS+LAN, 영속 싱글톤) / `NetRacer`(거리·레인·IsReady·AI) / `NetRaceCoordinator`(로비/START/카운트다운/AI채움/레인앵커) / `NetAvatar` / `MultiplayerHud` / `LanDiscovery`(UDP 발견+수동 IP) / `ItemNetworkRelay` / `TitleLobbyNetBridge`(타이틀 UI↔네트워크).
- 기존 변경(하위호환): BoatMover.ApplyNetworkDistance, RaceManager.RegisterRacer/RacerCount/BuildStandings(racerNumber), GhostRacer.ApplyExternalSlow/InitForNetwork, ProtoBeatmapSpawner.StopSong/RestartSong(시드).
- **검증**: 자동 빌드/테스트 루프(`DevBuildScript.BuildWindowsDev` + `VR1Team.exe -lanhost/-lanjoin [-autostart]`)로 2인스턴스 접속→레이스 확인. 4인 실접속도 사용자 확인.
- 흐름: 타이틀 Start=LAN호스트 / Join=LAN조인 / 로비 Ready→전원 START→레이스 씬 동시 이동→카운트다운→레이스. 완주자 대기→전원 완주 시 결과→재시작(세션 정리).
- **공정성 수정**: SpeedController.ResetForRace(접속 전 누적속도 제거), 채보 시드 동기화(전 기기 동일 노트), 시작선 정렬(레인 앵커=PlayerBoat+Ghost1~3).
