리듬 게임의 **손맛**과 레이싱의 **경쟁심**을 한 판에 결합했다. 플레이어는 VR 컨트롤러로 날아오는 노트를 직접 타격하고, 잘 칠수록 보트가 빨라져 결승선에 먼저 도착한다.

---

## 2. 기획 의도 & 차별점

### 왜 이 게임인가

- 리듬 게임은 보통 "제자리"에서 점수만 쌓는다 → 여기에 **공간 이동(레이스)** 과 **타인과의 경쟁**을 더해 긴장감을 만든다.
- VR은 "직접 몸을 쓰는" 매체 → 버튼이 아니라 **실제 팔 동작**으로 노트를 치는 손맛이 핵심 재미.

### 차별점 3가지

1. **실력 = 속도.** 콤보를 잘 이어갈수록 보트가 빨라진다. AI는 플레이어 속도를 따라하지 않아(미러링 금지) **잘한 만큼 앞서는** 정직한 보상.
2. **교실에서 같이 노는 4인 멀티.** LAN 기반이라 인터넷 없이도 한 공간에서 바로 대전 — 수업/전시 친화적.
3. **카트라이더식 역전 아이템.** 꼴찌일수록 강한 견제 아이템이 나와 끝까지 결과를 모른다.

## 3. 핵심 게임플레이

### 코어 루프

```
노트 등장 → 색에 맞는 손/도구로 타격 → 콤보·속도 ↑ → 보트 전진 → 결승 순위 정산
                                  ↘ 아이템 노트 → 자기강화 / 상대 견제 ↗
```

### 노트 & 타격

- 노트 4종을 **색**으로 구분 — 파랑/초록/빨강 날치 + 흰 새(아이템).
- 동작도 구분: **빈손 터치 / 잡기(Grab) / 트리거 / 양손(아이템)**.
- 타격 도구는 **추상화**되어 손·후라이팬·노 등으로 교체 가능(코드 변경 0).
- 노트는 **팔 거리 앞**에서 처리되고 맞으면 튕겨나가 시야를 가리지 않는다(VR 가독성).

### 콤보 → 속도 (실력 보상)

- **콤보**: 미스 시 0으로 리셋(리듬 게임 정석).
- **속도**: 히트마다 +가속, 미스마다 −감속이 **누적** → 한 번 실수해도 속도가 0이 되진 않음(좌절 완화).
- 플레이어 속도 곡선: 시작 ~6 → 잘하면 ~18-20 m/s.

### 판정 철학

- **타이밍 등급(Perfect/Good) 없음** — VR 기기 입력 특성상 밀리초 판정이 부적합하다고 판단(팀 합의). "쳤다/놓쳤다"의 명확한 손맛에 집중.

## 4. 게임 모드 & 콘텐츠

### 곡 & 난이도

난이도 단계별로 곡을 제공. 각 곡은 **BPM에 맞춰 제작된 채보(CSV)** 로 노트가 떨어진다.

| 단계  | 곡                               | 난이도 | 특징                         |
| ----- | -------------------------------- | ------ | ---------------------------- |
| 1단계 | Bubble Jump                      | EASY   | 한 박에 1노트, 규칙적        |
| 2단계 | Breathe Breeze                   | NORMAL | 1.25노트/박, 약한 신코페이션 |
| 3단계 | Dream Vessel                     | HARD   | 1.5노트/박                   |
| —     | Tavern Tide Turn / Barnacle Beat | HARD+  | 고밀도 자동 채보             |

- **곡별 결승 거리**: 곡 길이·난이도에 맞춰 결승선을 다르게 설정 가능.

### 멀티플레이 (최대 4인)

- 타이틀에서 호스트/조인 → 로비에서 곡 선택·레디 → 호스트 START → 전원 동시 출발.
- **빈자리는 AI가 자동으로 채움**(2인이면 AI 2척 추가해 4척 레이스).
- 결과창: **완주 순위 + 완주 시간** 표시.

## 5. 아이템 시스템 (5종)

아이템 노트를 치면 **내 등수에 따라 가중치로** 하나를 뽑아 즉시 발동(카트라이더식).

| 아이템       | 분류     | 효과                                          |
| ------------ | -------- | --------------------------------------------- |
| **부스트**   | 자기강화 | 일정 시간 속도 급상승                         |
| **무지개별** | 자기강화 | 무적 — 노트 자동 명중 + 폭탄 무시 + 견제 면역 |
| **자석**     | 자기강화 | 파란(터치) 노트만 등장 → 쉬운 콤보            |
| **폭탄**     | 견제     | 상대 레인에 함정 설치                         |
| **우주선**   | 견제     | 현재 **1등**을 감속                           |

- **역전 설계**: 선두는 약한 자기강화 위주, 꼴찌권은 견제(폭탄·우주선) 확률↑ → 끝까지 순위 변동.
- 우주선은 내가 1등이면 드롭되지 않음(앞에 1등이 없으면 무의미).

## 6. 기술 설계 (핵심 어필 포인트)

### 6.1 가벼운 멀티플레이 아키텍처

- **리듬·판정·속도 계산은 전부 로컬**에서 수행.
- 네트워크로는 **보트 누적 거리 + 아바타(머리·양손)만** 동기화.
- 공격 아이템조차 **RPC로 "신호"만** 보내고, 효과는 **대상 기기 로컬**에서 처리.
- → 풀 상태 동기화보다 훨씬 가볍고 **지연(랙)에 강함**. 기존 싱글 코드를 거의 그대로 재사용.

### 6.2 VR 멀미 방지 설계

- 보트가 직선으로 전진(객체 이동) — 텔레포트/스냅턴/그랩무브 **전부 잠금**.
- `Tracking Origin = Device`, `Camera Y Offset 1.6` (앉아서 선 시야).
- 출렁임(BoatBob)은 **배 모델에만**, 카메라엔 회전을 주지 않음.
- 타격 판정은 **레퍼런스 프레임 로컬 속도** 기준 → 보트가 움직여도 정확.

### 6.3 BPM 자동 분석 채보 파이프라인

- 음원(WAV)의 PCM을 직접 분석 → **온셋 에너지 + 자기상관**으로 BPM·다운비트 자동 검출.
- 검출한 비트 그리드 위에 난이도별 밀도로 채보를 생성.
- 생성된 채보가 실제 음악 온셋에 정렬됐는지 **객관 검증**(노트 위치 강도 = 전체 평균의 5~8배).

### 6.4 도구/노트 추상화

- 타격 도구는 `Striker.hitPoint`만 교체하면 무엇이든 됨(손/후라이팬/노).
- 노트·판정은 프로토타입 단계로 **정식 리듬 엔진으로 교체 가능**한 구조.
